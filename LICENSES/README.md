# Preserved third-party licenses

This directory preserves exact installed-wheel license/notice files and the licensing/attribution files from matching official dependency source archives. Third-party copyrights and license choices remain with their authors. The application's root LICENSE applies to project-authored code.

See `manifest.json` for text hashes and origins, `dependency-sources.json` for matching source versions/locations, and `docs/BINARY_LICENSES.md` for binary redistribution, corresponding source and rebuild instructions. The standalone GPL/LGPL texts supplement the component notices.

The Qt commercial reference supplied by its wheel is not used as an open-source license. Matching open-source Qt/PySide texts are preserved instead. Additional notices may be retained for source/build tooling; inclusion of a text does not imply that every optional upstream component is shipped.
