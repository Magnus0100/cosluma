# 自动人物环境光色协调

软件在整图与上下文审片确认“人物场景融合缺少局部后期”时，增加一次本地环境响应修复。用户使用“已有参考完整后期”或“重新审片并本地修复”，无需为单张照片指定光源方向、画区域或调参数。

## 方法与数据流

原片的身份、几何和纹理作为人物基底。已有 T/B/S 仿色及明暗层先形成当前人物端点；独立 DINOv3 局部对应确定原图像素对应的参考位置。该模块只观察同语义材质内参考与当前端点的宽尺度 EV 和 OKLab 色度残差，再求一个低频调整场。

置信度用于观测权重；有有效观测的平坦区域不会因为置信度较低而固定降低颜色剂量。缺少对应的区域保持未知。源材质边界约束求解和升采样，作用范围在有效对应边界渐退；没有由全图均值推断的方向，也没有自动生成的等宽轮廓线。

校正场使用 `validated_proxy_owner_edge_v2` 宏观引导策略。求解前对源引导做区域内低通和固定中值统计，保留持续的大材质分界；求解后按区域尺度进行 Laplacian 正则化。窄滚边、织纹和颗粒不会被当作独立受光区域。每一折留出验证和最终生产执行相同的正则化，再检查实际像素响应；原尺寸上采样使用同一宏观引导，不让原片细纹改变光色剂量。原片人物 RGB 始终不参与空间模糊。

当前人物与映射参考的低频观测共用源材质宏观分区和空间尺度，避免参考滚边错位被当成人物需要局部提亮。参考目标在过滤前隔离留出块；留出值不会进入训练的分子、引导或支持权重。

当前处理有可靠对应的头发和衣料（源语义类别 4、1、13、23）。空间分块留出检验实际应用后的剩余明暗与色度误差，包含高光和色域限制；不能改善留出观测的部分不生成修复。留出验证约束光色场的预测能力，几何资格仍由独立对应证据提供。

当前已匹配区域产生零或很小的残差，减少重复染色。参考人物 RGB 和高频纹理不会写入输出；原片像素接受逐点光色变化后，冻结为源原尺寸坐标中的稀疏预乘 RGB 增量。透明度、人物坐标、背景、脸和眼口保持原有资产。

## 保存与重新打开

`scene_integration / scene_composition / retouch_missing` 路由到人物环境响应生产者。背景数据一致性修复保持原来的职责。每个当前任务最多一次本地尝试，不新增生图预算。

新像素保存为自持资产的子版本。父版本、原审片和工程选择保留，新版本必须取得自己的完整审片；数值改善不授予艺术质量通过或人工批准。全图、原尺寸 ROI 和预览使用同一冻结原尺寸增量，预览在原尺寸形成支持后缩小。

更改仿色强度、原片基底、透明度、独立语义、先行人物细节或前景控制，会使冻结端点不再适用。重开不偷偷重算模型或补一次修饰。资产损坏或绑定变化会明确拒绝。

## 当前范围

局部暖反光、明暗与色偏可由宽尺度参考证据提供。无对应的细发丝、皮肤响应、物理投影和完整三维光照不由该模块推断。已启用下游前景手动处理或独立效果的最终端点，目前须先取得可分离端点证据；不会把这些像素当成同一人物端点。

生产模块为 `subject_environment_field.py`、`subject_environment_worker.py`、`subject_environment_runtime.py` 和 `automatic_subject_environment_completion.py`。
