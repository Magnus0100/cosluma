# Alpha / Matting 验收策略

更新时间：2026-10-04

这份策略用于下一阶段的生产评审。alpha 是“允许高清原片写回最终图的权重”，不是人物分割真值。所有 backend（polygon、U2Net 或未来 matting）都必须先转换成这个写回权重，再交给相同的 `structure-safe`、合成和人工确认流程。

## 会议结论

当前两组样例已经支持一个可交付的单张流程：人工修正的 polygon alpha + alpha-trust appearance fit + `structure-safe`。`DSC02634` 的真实原片交付记录为 scale 1.01、平移 (-2, 16)；对齐后的结构分歧 p95 为 0.39，约 2.96% proxy 像素高于 0.5。分歧集中在脸、头发、抬手、逆光轮廓和新增光效，不能靠追色 operator 消除，应降低这些位置的 alpha 让 GPT 下层保留结构。

结论是：

- **polygon** 是当前默认 backend。它可复现、无需下载、容易人工修改，足以覆盖稳定服装和身体区域。
- **U2Net** 只作为可选 silhouette 提供器，不是最终 alpha，也不应直接决定人物写回范围。它适合减少粗轮廓描边时间，但仍需 confidence profile、structure-safe 和人工修边。
- **structure-safe** 应作为默认保护层。它只在手工/模型 alpha 内部降低写回权重，不会把 mask 扩到背景；它处理的是 GPT 重绘造成的结构不一致，不替代 matting。
- 当前没有证据表明需要强制下载 BiRefNet、MODNet 或其他 matting 模型。先把一次人工确认做成稳定生产入口。

## Alpha 分区规则

| 区域 | 默认写回权重 | 判定原则 |
|---|---:|---|
| 黑色外套、白色马甲、裤装、稳定饰品和织物纹理 | 0.65–0.85 | 原片纹理清楚，GPT 主要改变颜色/光影 |
| 身体中部、没有明显重绘的手臂 | 0.55–0.80 | 保留真实高频，但不强行覆盖 GPT 光影 |
| 脸、妆容、五官和明显美容区域 | 0.00–0.35 | GPT 美学优先；只回写少量皮肤、眉毛、睫毛细节 |
| 头发、飞发、手指尖、薄纱、轮廓光 | 0.00–0.35，边缘使用灰度过渡 | 这些区域最易错位或被 GPT 重画，禁止硬白边 |
| GPT 新增火焰、粒子、烟雾、太阳光、前景物件和背景高光 | 0.00–0.10 | 直接保留 GPT 下层，不让 operator 伪造新内容 |

数值是起始范围，不是自动分割阈值。最终以 100% 局部和缩略图同时检查为准；如果 alpha=1 的区域产生双影，应优先降低 alpha，而不是继续调 operator。

## 三种 backend 的验收边界

### Polygon

适用于当前已知姿态和少量样例。验收重点是轮廓覆盖：头顶、抬手、肩部、手指和裤腿不能被截断；人物外的光斑、桥梁和雾不能进入实心区。多边形不能表达飞发和半透明饰物，允许在这些位置保留较低 alpha 并由人工刷灰度边缘。

### U2Net

只比较它是否减少“画出主体大轮廓”的时间。不要用 IoU 或白色面积作为唯一标准；U2Net 可能把包、道具或轮廓光一起分出来，也可能吞掉飞发。输出必须经过 `apply_confidence_profile`，默认头部低权重、身体中部约 0.72 上限，再由 `structure-safe` 抑制与 GPT 结构分歧的区域。若 U2Net 结果仍需大量擦除才能满足下列硬门槛，就回退 polygon，不把模型设为默认。

### Structure-safe alpha

必须满足三个性质：

1. 只调制已有 alpha，绝不向背景扩张；
2. 高分歧位置保留 GPT 下层，不覆盖 GPT 新结构；
3. 在服装和身体稳定纹理上不产生大面积透明洞。

每次生产输出都查看 `structure_mismatch.png`。热区若落在脸、发丝、抬手和轮廓光，属于预期保护；热区若覆盖整件稳定服装，先检查对齐参数，再决定是否人工调整 mask。

## 交付硬门槛

单张图只有同时满足以下条件才进入交付目录：

1. 输出尺寸与真实原片一致，`metadata.json` 记录原片、参考图、mask、对齐参数和 structure-safe 参数；
2. 100% 局部检查人物身份、眼睛、手指和服装几何，没有新增肢体、明显双眼或大范围错位；
3. 头发、手指和逆光边缘没有连续的彩色 halo 或硬白边；少量灰度飞发过渡可以接受；
4. GPT 的脸部美化、右上方光效、粒子、烟雾和背景设计仍然明显存在；
5. 黑色外套、白色马甲、饰品和织物纹理在 100% 局部仍来自高清原片，未被放大 GPT 图的模糊纹理替代；
6. 只需一次短暂 mask 确认或少量笔刷修补即可完成。若同一张图连续修边仍超过约 30 分钟，才开启 U2Net/matting A/B；模型结果不能绕过人工确认。

## 人工与自动化边界

自动化负责：proxy 对齐、operator 拟合、候选 alpha、结构分歧热图、分块高清渲染、两层合成、metadata 和 manifest。人工只负责：确认 GPT 是否重画了脸/头发/手部、在结构热区把 alpha 刷低、补回稳定服装/身体纹理，以及最终 100% 局部复核。

matting backend 的职责到“提供更好的初始轮廓”为止。它不能自动决定 GPT 美术和原片纹理的取舍，也不能把生成式重绘区域变成可信原片。任何新 backend 都必须与 polygon 在同一张图上做 A/B，比较人工修边时间、halo、身份保持和 GPT 光效保留；仅仅提高分割面积或模型分数不足以替换默认路径。

## 下一阶段执行顺序

1. 用 `scripts/build_final.py` 对真实原片目录生成一次 manifest；默认沿用人工 `mask_review`，打开 `structure_mismatch.png` 做热区检查。
2. 只在 DSC02634 上做 U2Net A/B，保留同一 confidence profile 和 structure-safe 参数；记录人工修边时间和四个硬门槛结果。
3. 若 U2Net 没有减少修边时间，回退 polygon，开始处理 16 bit/ICC 和交付文件命名；不要继续堆 matting 模型。
4. 若 U2Net 明显减少粗轮廓工作，再考虑单一 matting refinement；仍保持一次人工 alpha 确认，不引入多模型串联。
