# 原景编辑与已有参考工具

新建任务使用当前制作范围合同：精修、半合成、大合成；风格另选自然、鲜明、戏剧。默认本地 Qwen 半合成、鲜明风格，原室内外关系不变。人工精修样张用于理解质量，不是默认必需输入，也不按单张样张改源码。

## 新建任务

桌面、CLI 和 HTTP 均通过 `task-plan` / `task-start`。合法的 `create_reference` 请求省略 `editing_request` 时，检查计划规范为 `partial_composite + expressive + target_setting=same`；显式精修走 `local_portrait`。创建请求中的旧 `reference_role`、`refinement_profile`、`creative_direction` 及原生 `regional_refinement` 路由已删除并拒绝，不会转换为兼容方案。

执行顺序为：观察原片并冻结编辑设计 → 准备原生精度基线并真实评价 → 模型选择首次局部或整体编辑 → 独立审片与有界条件改进 → 保存较好完整版本与导出。局部编辑保留许可区外原生 float 像素，整体生成承担全图纹理代价；模型依据任务目标选择。原生、局部和整体外观分别冻结实际像素来源，不把原人物 RGB 或固定源 Beauty 整体盖回生成受光。生成纹理不冒称相机原生细节。

默认独立审片开启，最多两步通常改进及最后一次仅允许零生图工具或停止的收尾。单候选计划最多 3 次图像、10 次视觉请求，实际用量取来源账本。收尾不增加生图额度，显式只设置一次改进不增加收尾。首次编辑与后续轮次分开，基线保存不代表已完成修改。模型只从具备真实输入资格的工具中选择，未执行的条件节点不记完成。未知与停止决策占用原轮次，重开不刷新；缓存和零图像 CPU 工具不冒充生图。

半合成允许适量场景修改和符合角色的效果，保留场地逻辑；室内不能悄然改室外。替换场地需显式大合成授权。身份、妆造、表情、姿态、形体、服装和重要道具为保留事实。自然可信度和创作收益分别评价，自动审片不等于人工接受。

提交前持久预留额度。超时、取消或结果未知不自动补发；未完成版本不成为最新成片。保存、重开与导出使用冻结资产，不隐式重新推理。用户明确反馈可以申请新的有界改进任务，父审片通过不证明新的反馈目标已满足。

## 仍有效的已有参考工具

普通 `existing_reference` 默认新增图像为 0，仍使用源图几何与原生图层工具。显式同照校准、具备真实同源 provenance 的 `source_conditioned_design`、冻结 Beauty 及原生区域工具，仅按已检查用途执行；它们不再是创建新图的默认路径。

已有参考显式申请单区编辑时，检查计划单独授予局部最多 1 次额度。许可区必须在人物覆盖之外并保留安全边带；模型画布上下文不扩大 CPU 写入权限。零图像复用已返回候选和恢复未提交局部步骤仍需核验原片、参考、区域、journal 及真实任务身份。已提交、未知或完成的请求不续发额度。普通打开、保存、重试与最终本地修复均不授予新额度。

已有参考中的 T/B/S、Beauty、配准与源图引导低频映射仅服务该工具链。配准或覆盖不足时保留源图并报告缺口；原生纹理、生成纹理和未经证实的背景分别记录来源。

## 当前范围

### 可选校准：对照同一张照片的精修成片

在“已有参考＋原景增强”中，可显式勾选“对照同一张照片的精修成片”，对应`reference_role=same_photo_finish`。这是可选校准，不是默认原图流程的前提。原图是几何与原生细节载体，用户精修图只提供光色标尺；该用途不能同时申请区域生图或沿用旧的生成恢复授权，新增生图预算始终为0。检查计划冻结双方SHA和用途，并如实显示配准尚未执行。

执行时先准备当前原生人物与场景，然后核验同照特征、覆盖与变换健康度，在最终组合画面上拟合源图边缘引导的局部仿射色彩系数。参考RGB不直接贴入成片，原图像素坐标与alpha不移动。系数的局部增益受约束；出显示色域时沿原像素到映射像素统一退量，避免逐通道硬裁造成色带。

冻结后的系数、用途和实际配准回执随工程保存，整图、原尺寸ROI和显式缩放预览使用同一算子。普通重开不再配准或拟合；明确重新准备时先移除旧算子，再基于当前未套同照光色的组合画面拟合。原生高频由源图决定，但色彩映射会改变其对比和响应，因此不声称纹理逐像素不变。

这不是自动分材质、恢复真实灯光或拆出透明雾叶图层。裁切外的光色延拓是外观估计，局部液化、新增发丝和前景实体细节不由该算子恢复；须按实际原尺寸结果审查。

同样，默认原图驱动路线中的局部光色算子只能改变已有像素的低频外观，不能凭空生成新的薄雾实体、红叶、发丝或道具。生成参考里出现这些内容不等于原生成片已合成它们；若源图没有对应内容，必须有明确授权和实际消费的内容资产／生成阶段，否则保持未履约，不能把色彩改善说成雾叶已经完成。新增内容的许可与预算也不能从光色合同隐式取得。

合同和 CPU 回归验证输入、范围、来源和冻结回放边界。每张照片的质量仍以实际保存全图及相关原尺寸窗口审查，人工批准单独记录。

桌面异步生产链在独立本地Python进程执行同一CLI；原生计算异常记录为任务失败，保留输入和旧作品，不自动重试。此隔离不等于已定位所有原生异常原因，也不改变图像生成预算。

界面预热与独立制作进程通过本地受控通道使用同一美化服务。状态、实际服务身份、提交、进度、取消和GPU阶段释放保持同一所有者；只有真实驻留且配置一致的模型才按已加载状态计算增量。GPU互斥卸载后如实恢复冷加载预算，预热、卸载和重载分别记录，不以历史成功结果冒充当前驻留状态。

这是单区域、有上下文的受控编辑，不是MultiDiffusion或任意7K联合扩散。上下文不能保证模型不移动结构；几何／内容漂移不能靠羽化修好。高分辨率容器也不代表恢复了原图中不存在的细节。

角色效果可以是非发光的情感意象，不默认法阵、血腥或全身描亮边。主效未实施或证据不足会保持未知／待审，不能因节点成功而标为已完成。各阶段实际用时与缓存命中写入当前账本，未测量的区域路线不给固定ETA。
