## 结论

两组数据已经足够启动 Demo。每组都形成了完整的三元组：

```text
高清原片 JPG → GPT 参考图「参考.png」
             ↘ 人工高分辨率成片 PNG
```

三类图的宽高比完全一致，未发现需要先做裁切的证据。相同编号的三张图在构图、人物姿态和桥梁背景上保持同源关系；先前按缩略图产生的“交叉配对”疑虑已通过单组并排查看和结构相关性排除。

## DSC02631

原片整体偏暗、偏冷，背景桥梁和人物服装的真实纹理清楚，但没有明显的金色光斑和粒子。人物正面站立，人物轮廓和服装结构稳定。

GPT 参考图增加了右上方暖色逆光、发丝轮廓光、背景高光和散落粒子，同时提高人物脸部与白色衣服的可见度。脸部存在明显的美化和肤色整理；头发边缘的亮线与背景光联系紧密。人工高分辨率 PNG 与 GPT 参考图的构图和整体效果非常接近，适合作为最终成片验证目标。

抽样统计（统一缩放到 256 × 384，仅用于诊断）：

- 原片平均亮度约 78.5；人工图约 80.9；参考图约 81.5。
- 参考图与人工图的灰度结构相关性约 0.988，说明该组的几何与主体内容非常稳定。
- 原片到参考图的差异主要是 appearance edit 和背景光效，不是重画整个人物。

建议 alpha：

- 服装、饰品、手部和身体纹理：0.7–1.0；
- 脸部：0.35–0.65，保留 GPT 的美化，同时从原片补回眉毛、睫毛和皮肤高频；
- 发丝外缘和轮廓光：0.2–0.6；
- 背景高光、粒子、暖色光晕：接近 0。

这是首选的 BGU 验证样本：appearance 变化明显但结构改动相对温和。

## DSC02634

原片同样偏暗偏冷，人物姿态变为抬手触碰头发，主体服装和桥梁结构仍然清楚。GPT 参考图和人工 PNG 都加入了更强的右上方金色太阳光、雾化高光、粒子和衣服边缘提亮，整体亮度和暖色显著高于原片。

抽样统计：

- 原片平均亮度约 79.0；人工图约 96.3；参考图约 96.0。
- 人工图与参考图都接近同一组构图，但该组的脸部、发丝、背景光斑和局部亮度变化比 DSC02631 更强。
- 原片到参考图的全局像素结构相关性较低，不能据此判断配准失败；主要原因是强烈的局部光效、亮度重分布和人像美化。Demo 必须同时看边缘/梯度和视觉叠图。

建议 alpha：

- 黑色外套、白色马甲、裤装和饰品的稳定纹理：0.7–1.0；
- 脸部和手部：0.3–0.6；
- 抬手处的头发、手套边缘和轮廓光：0.2–0.6；
- 右上方太阳光、粒子、背景雾和高光地面：接近 0。

这是第二个压力测试样本，用来判断局部 appearance transfer 是否足够，以及 alpha 边缘是否出现原背景色 halo。

## 对第一版算法的判断

### BGU / operator transfer

适合承担主要的局部色调与亮度迁移，尤其是 DSC02631。DSC02634 的强逆光可以检验空间局部映射，但 BGU 不应被要求生成原片中不存在的太阳光、粒子和雾；这些内容必须由 GPT 下层提供。

十小时 Demo 采用“局部网格 affine operator + 低分辨率引导”的可解释 baseline，优先保证能在两组真实图上产出可观察结果。它不是最终 BGU 论文实现，但足以回答是否值得继续投入。

### 配准

宽高比和主体位置稳定，默认同坐标处理；加入小范围平移搜索和可选缩放参数即可。第一版不需要 dense correspondence，也不需要先下载大模型。

### matting / alpha

当前没有现成 mask。十小时 Demo 先使用可复现的中心主体软 mask，并把 mask 保存为独立 PNG，允许用户后续替换或刷改。这个 mask 只用于验证两层融合，不宣称已经解决发丝级 matting。真实产品阶段再接入单一 matting backend。

## Demo 成功判定

两组样本都应输出：

1. 高清原片的 appearance-styled 版本；
2. 放大后的 GPT 参考图；
3. 软 alpha mask；
4. 两层合成图；
5. 原片、参考图、人工成片、Demo 合成图的对比图。

如果 DSC02631 的人物纹理和 GPT 光效能自然交接，且 DSC02634 没有明显 halo 或人物身份改变，说明最小架构成立，可以进入真实 matting 和更强局部 operator 的迭代。
