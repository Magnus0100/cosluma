生产入口、冻结资产和恢复动作见 [产品数据流](PRODUCT_ARCHITECTURE.md)。模型由当前注册表配置，缺少权重、运行时或有效身份时明确失败；程序包不含模型。以下说明已接入的职责，不把研究计划、模型名或检查数量作为艺术成绩。

## 当前质量边界

- 局部原生通过只覆盖实际匹配窗口；整图通过不认证全图原生纹理。未知、未观察和未支持区域继续显示。
- 发梢仍有较厚亮弧及碎点；明确肩头窄高光脊、完整强肩袖轮廓光、前臂与袖口收益未完成。边界受光只接受已受检的有界改善，详见 [人物边界受光](BOUNDARY_LIGHT.md)。
- 原生人物细节恢复不能由统一仿色、曝光或未确定噪声触发；无法区分结构和噪声时保持原像素。方法见 [人物细节核验](AUTOMATIC_SUBJECT_DETAIL.md)。
- 人物环境协调只处理可靠对应的宽尺度光色，不能补推无支持细发丝、皮肤响应、三维光照或物理投影。方法见 [人物环境光色](AUTOMATIC_SUBJECT_ENVIRONMENT.md)。
- 自动接收面投影、镜面反射及低支持区域的可靠局部恢复仍有缺口；背景超分或数值一致性不证明材质视觉质量。
- 同场回归与单图有界艺术通过不能代表跨人物、妆造和场次的泛化验收。失败和未知应保留在实际评估中。
- scoped 区域编辑的边界归属按**本轮授权操作**判定，而不是按核心区内是否有主体；此前按主体存在无条件收窄会让 `scene_edit` 授权的场景侧交付改动量变成 0，属静默丢弃授权内容，已废止。规则与复现口径见 [Cos 成片标准](COSPLAY_POST_STANDARD.md)。

- 跨边界光照残差的归因按实测隔离臂给出，不按层名猜：685 核心几何的 `band/interior` 在父级自身已是 1.0549；同一主体 matte 臂开启联合增益为 2.7520、关掉 `_boundary_light_gain` 后为 2.7335（差 0.0185），无 matte 的全核心写入臂为 2.6312，常量配准臂（registration 保持常量）为 2.7335。即双向增益只移动约 0.02，残差主体来自**主体 matte 的形接合过渡**与 **provider 写入带内的内容幅度**，不是增益或带内 ±3EV 截断。命令：`python -B measure_case.py 685`（工程目录内的测量脚本，真实 run 资产 + 真实 `fuse_region` + `composite_quality` 同口径）。
- 报告与文档中的成片数值**必须标注臂**，否则不可复现：`subject_only=False` 是**默认路径**（写入整个授权核心，场景侧含在内，685 的 `written_fraction_of_core`=1.0、`boundary_source`=`authorized_rectangle`），`subject_only=True` 是仅主体轮（场景侧保留父级字节，`written_fraction_of_core`=0.4961）。同一 685、同一命令下：默认臂 seam 0.7863 / `registration.clipped_pixels` 0 / 带内截断 163,950 于 322,200；仅主体臂 seam 1.0611 / clipped 566,347 / 带内截断 1,628,542 于 2,644,850，`generated_detail` hf 0.547 对 0.4417。两臂都 `outside_region`=0、`under_zero`=0、coverage=0 处逐位一致。后续轮次的“前后”必须写清所走的是哪条臂。

新算法只有在正常观看与原生细节中取得净收益、保护身份妆造和材质，并完成实际保存与重开验证后才进入生产。被拒绝候选不成为备用入口。源码清理保留当前生产行为及已接受的艺术范围，不因删除旧入口新增视觉通过。

BeautyGRPO 的当前配置与使用见 [人像美化](PORTRAIT_BEAUTY.md)。

## 形体支撑半径由应变预算命名（0.7.5）

**问题**：`handle_reach_multiple=9` 是常量，不随请求强度自适应。当峰梯度出窗时限幅器只能削力，真实成片在 amount=0.30 时交付 84.3%（662）／82.3%（685），低于 attainment 0.90。

**证据**：外侧可用过渡距离只有所需的约 37%（662 27.95/75.46 px、685 43.44/117.29 px）；未限幅应变随 reach 变化且**非单调**（685：9→1.3179、16→1.2908、20→1.2468、28→1.2473），无法解析外推；多候选搜索在 685 上为 3.6× 耗时，不可接受。

**决定**：只做**一次**纠正。先按 9 建场，`strain_limited_fraction >= 0.999` 即返回（低档位逐像素不变）；否则用该次建场记录的 `required_inner_ramp` 与未限幅峰值算出候选倍数（实测 24.18／24.19，即「支撑 = 4 × 所需过渡距离」），再建一次并取 `maximum_control_delta` 更大者。

**理由**：应变预算本身已经给出所需过渡距离（`required_inner_ramp = 1.5 × 4 × δ`），常量 9 与它无关；让支撑跟随预算，比挑一个看起来好看的常量更有依据，也比扩大窗口或降低请求诚实。

**不改变的东西**：窗口 [0.8,1.25]、attainment 门限 0.90、所有指标口径一行未改；amount 0.40 仍判 fail（模型容量 0.3056 是几何上限）。

**代价**：耗时只在会削力的档位付出，且第二候选复用同一次建场的几何、全程只校验选中的场——amount .30 全程 662 10.66→7.73 s（1.38×）、685 26.93→20.92 s（1.29×；单次建场 5.64 s／16.73 s），`_geometry` 与 `_validate_structure` 调用各从 2 次降到 1 次，同一输入前后 mapping_id 与位移场逐位相同；向脸内的衰减形状会变平缓（余弦 0.9456／0.9464），控制点请求位移逐位不变。

## 0.7.5 决策

1. **形变支撑半径由应变预算命名**（已实施）：先按 `reach = 9 × 峰值` 建一次场；若 `strain_limited_fraction >= 0.999` 原样返回（低档位逐像素不变：662 147,467 px、685 320,816 px 与 0.7.4 一致）；否则取 `4 × required_inner_ramp / 未限幅峰值` 重建一次并保留控制位移更大者，倍数上限 64 并记录 `candidate_capped`。窗口 `[0.8,1.25]`、`attainment_min 0.90`、任何断言未动。`amount=0.40` 仍 fail：容量 `admitted_inner_band/(6×0.03×face_width) = 0.3056`，该档处于 130.9%，属几何容量而非参数。
2. **生成细节判据不动**：`hf_ratio` 可分解为 `区域自相似 × 曝光比 × 接合保真`（662 `0.6154×0.8465×0.729 = 0.380`、685 `0.9512×0.6973×0.808 = 0.536`），只有第三项属于接合。在指标自己的域里，恒等对照 662 `0.6154`、685 `0.9512` 均过线；配到交付曝光后 662 `0.5270`（差 4.4%，要过线需区域细节达母版自身区域的 `0.8938`，拷贝只给 `0.8563`）、685 `0.6768` 仍过线。因此不得把 provider 自身的内容上限当作判据或过闸手段。
3. **色相台阶轴新增但为临时测量**：`hue_step_excess` 复用既有壳几何，比较交付与母版在同一位置的有符号 `(a*,b*)` 台阶；因色度读数是模、对色相旋转不敏感，该轴并列记录而不是替代色度。它计入报告并逐位自校验，但**不进 `failed_items`/verdict**（`PROVISIONAL_ITEMS`），直到 ≥5 例真实成片完成标定——与色度「n=2 不设判据」同一把尺子。

## 0.7.5 未采纳、记入 0.7.6

- **D1**：8 例真实母版复跑四轴数值；`amount > capacity` 在规划期显式拒绝或降额并告知，而不是交付后才判 fail。
- **D2**：provider 自身内容的上限进报告（需给 `measure()` 增加 `provider` 关键字，属 API/schema/validate 变更）；纹理界 `noise_ratio_bounds (.4,4.) → 8.0` **判定不纳入 0.7.5**——它只放大 provider 自身残留（685 `0.5470 → 0.5984`）而不恢复信息，且 662 放到 16.0 也只到 `0.4383` 并饱和。
- **D3**：近零分母下的稳健求解（662 带内 61.2% 像素至少一通道恰为 0，比值发散）；`±3 EV` 界保持不动。
- **D4**：色相台阶轴达到 ≥5 例后重新标定，再决定是否作为判据。
- **D5**：8 例的四轴数值（细节/带内截断/色度/形变）尚未产出，本轮只交样本与可重跑输入。
- **D6**：672（生产检测器 0 脸）、704/705（仅 RAW）补位；禁止用合成夹具充当真实案例。
