# 当前算法选择与范围

生产入口、冻结资产和恢复动作见 [产品数据流](PRODUCT_ARCHITECTURE.md)。模型由当前注册表配置，缺少权重、运行时或有效身份时明确失败；程序包不含模型。以下说明已接入的职责，不把研究计划、模型名或检查数量作为艺术成绩。

| 责任 | 当前实现与边界 |
|---|---|
| 原片/参考局部对应 | DINOv3 ViT-L/16；对应是局部支持依据，不证明逐发丝或褶皱精确注册 |
| 场景概念与地面实例 | `sam31_static_detector_v1`，SAM3.1 Multiplex detector、Tri backbone和官方处理器，严格完整加载；实例不是透明度、深度或RGB |
| 人体语义 | Sapiens2 0.4B；标签提供位置归属，不是真实材料或光照 |
| 人物透明度与前景 | BiRefNet引导、原生ViTMatte及PyMatting前景/背景分离；不使用软椭圆回退 |
| 五官证据 | 本地landmark与独立源语义；不可靠时保留unknown，不用整脸替代眼口 |
| 背景清理与超分 | 当前LaMa/RealESRGAN注册资产及真实有效区；不接管人物结构 |
| 仿色与材质 | 当前对应/支持和owner-adaptive multiscale v2，颜色与明暗分别估计，冻结原生四角点银行 |
| 宏观融合 | 原片/参考低频差异、源材质宏观边界和场景明暗平衡；不声称完成物理重光照 |
| 人物细节恢复 | 已审片匹配窗口、独立源结构及实际频带损失资格；只恢复冻结原片亮度细节 |
| 人物环境响应 | 当前端点低频EV/OKLab残差、源边界约束及空间留出；无对应或无实测改善保持开放 |
| 发梢受光 | 参考头发正响应与源亮度细节，独立原生层；外观转移，不是物理光照 |
| 肩袖暖光 | 合格不透明外衣的粗光色系数与原片结构；已接受右肩/上臂暖面，不复制参考褶皱 |
| 两层联合更新 | 先发梢、后肩袖，完整资格通过才一起应用；取消、失败或无变化保留当前编辑 |
| 接地与接收面细节 | 共同地面、鞋语义、双透明度及匹配窗口；局部背景亮度恢复不制造投影或镜面反射 |
| 设计与生成 | 任务要求和双图身份绑定；已有参考路线生图预算为零，创作路线使用明确有界预算 |
| 审片与交付 | 全面QA、portable v2、真实TIFF16/32；技术证据、自动诊断和人工批准分别记录 |

SAM3.1的公开视频追踪改进不证明静态Cos照片全面优于其它检测器；当前选择依据受检任务和固定生产身份。局部模型输出、语义、置信度和支持只能为其声明的职责提供证据。

## 当前质量边界

- 局部原生通过只覆盖实际匹配窗口；整图通过不认证全图原生纹理。未知、未观察和未支持区域继续显示。
- 发梢仍有较厚亮弧及碎点；明确肩头窄高光脊、完整强肩袖轮廓光、前臂与袖口收益未完成。边界受光只接受已受检的有界改善，详见 [人物边界受光](BOUNDARY_LIGHT.md)。
- 原生人物细节恢复不能由统一仿色、曝光或未确定噪声触发；无法区分结构和噪声时保持原像素。方法见 [人物细节核验](AUTOMATIC_SUBJECT_DETAIL.md)。
- 人物环境协调只处理可靠对应的宽尺度光色，不能补推无支持细发丝、皮肤响应、三维光照或物理投影。方法见 [人物环境光色](AUTOMATIC_SUBJECT_ENVIRONMENT.md)。
- 自动接收面投影、镜面反射及低支持区域的可靠局部恢复仍有缺口；背景超分或数值一致性不证明材质视觉质量。
- 同场回归与单图有界艺术通过不能代表跨人物、妆造和场次的泛化验收。失败和未知应保留在实际评估中。

新算法只有在正常观看与原生细节中取得净收益、保护身份妆造和材质，并完成实际保存与重开验证后才进入生产。被拒绝候选不成为备用入口。0.4.8的清理保持现有生产图像行为及已接受艺术范围，不新增视觉通过。

下一大版本的人像美化候选、实际入口缺口和验证计划见 [人像美化调研与路线](PORTRAIT_BEAUTIFICATION_ROADMAP.md)，独立源码工具与真实推理范围见 [实跑与回放](PORTRAIT_BEAUTY_POC.md)。实验尚未接入上述生产能力。
