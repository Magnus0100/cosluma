# CosLuma — Windows 程序包

完整解压文件夹后，使用 `Start-Cosplay-Studio.cmd` 或桌面唯一快捷方式。保留 EXE 旁边的 `_internal`；默认工作区为 `%USERPROFILE%\CosplayWorkbench\workspace`。启动会尝试预热人像美化，实际加载成功后才显示完成。Qwen 配置、服务与模型加载状态分别显示；首个任务仍可能需要加载其他模型。

1. 默认“快速制作”中导入原片，选择“仅人像美化”或“完整 Cos 后期”，可补充效果说明。
2. 查看原片与当前效果，滚轮缩放和拖动联动，也可双击查看；美化完成后直接调整强度，处理中可取消。
3. 确认效果后保存高清版本，再导出成片。专业模式提供精修工具、原尺寸细节和可编辑工程导出，与快速制作共用工程及草稿。
4. 首次使用时在专业模式的“连接设置 → 配置分析模型”选择已安装模型与运行时，并配置完整 Cos 所需服务。已有参考不消耗图像生成预算，文本/视觉规划与外部审片可选；本地原片与美化路线可离线处理。专业制作入口可先检查计划、缺失项和预算。

需要保留拍摄现场时选择“原景增强”，填写角色和效果要求；原尺寸人物与可见背景继续提供细节。只有明确开启并选择一个背景区域时，才申请一次局部AI精修。先检查计划中的范围和额度，再开始制作；已有参考重制不续发区域额度。用原尺寸对照核查妆造、衣纹、原景结构和接缝。完整说明见[原景增强与局部高清编辑](SOURCE_SCENE_ENHANCEMENT.md)。

区域步骤若在实际提交模型之前失败，任务页可显式恢复该未提交步骤并复用已有参考；系统先核验零提交证明，只续作原区域一次。未知、已提交和已完成记录不会自动重发，界面会说明是否涉及局部生图。

BeautyGRPO 默认保留 100% 模型生成外观，接缝与真实遮挡单独融合，前额沿可靠皮肤向发际线扩展。可降低强度或在专业人像页按人脸恢复原片。模型输出、软件执行和人工艺术批准分别记录。

制作时显示阶段、阶段用时和累计用时；有至少三次兼容成功实测才给出预计剩余时间，否则显示“估算中”。保存或 AI 审阅通过后仍由用户检查当前版本并单独批准；导出草稿不等于完成用户批准。

升级程序后，打开旧版本会保留原来的保存效果。界面会说明该版本是否使用当前算法；点击“按当前算法重新制作”会复用原片、参考和美化，重新处理并保存一个新版本，不新增生图。启动默认打开最新保存结果；如果主动选择过历史版本，则保留该选择。

专业 Cos 画布提供预设、已有节点开关/强度、布局及模板保存/加载；连线固定表达现有流水线，当前未实现任意 DAG 或自由接线。

模型放在 EXE 同级的 `model` 文件夹。点击主界面“模型管理 → 自动查找已有模型”，或选择一次模型总目录；分析模型和 BeautyGRPO 会分别显示状态。标准目录和相对路径说明见 [model/README.md](../model/README.md)。已有源码项目的安装也能自动恢复，不需重新下载。逐项路径和 JSON 导入位于高级设置，配置保存在用户目录并用于后续启动。

程序包中的 `providers/beautygrpo.example.json` 是美化配置模板。独立运行时和权重仍须安装，详细字段见[人像美化配置](PORTRAIT_BEAUTY.md)。

“同时更新边界受光”可准备发梢和肩袖两层，预览后保存一个新版本。发梢从参考提取连续、有界的低频受光，保留原片发丝结构；衣料支持右肩／上臂柔和暖色布面。强窄轮廓光、前臂收益及跨照片效果仍待验证。详见 [边界受光](BOUNDARY_LIGHT.md)。

指定工作区可在程序目录运行：

```powershell
.\cosplay-workbench.exe --root "D:\My Cosplay Project" --embedded-backend --auto-start-backend
```

双击 `Start-Cosplay-Studio.cmd` 可读取相邻 `.env`、`.env.local` 中的字面量配置。直接运行 EXE 时，在连接设置中配置，或预先设置进程环境变量。

程序包包含桌面依赖和许可，不包含模型权重、模型运行时、私人照片、工程或凭据。开发脚本、自动测试、构建工具及 Qwen 安装启动器位于同版本 `source.zip`；文档中“从源码运行”和构建命令需先解压源码包。
