# CosLuma — Windows 程序包

本包为 0.7.1 正式分发版。完整解压文件夹后，双击 `cosplay-workbench.exe` 或使用 `Start-Cosplay-Studio.cmd`；无需安装桌面 Python。模型权重、模型推理运行环境及视觉服务需单独配置，详见[安装指南](INSTALLATION.md)。

保留 EXE 旁边的 `_internal`；默认工作区为 `%USERPROFILE%\CosplayWorkbench\workspace`。启动先打开本地后台，读取保存的制作方式与服务选择；默认 Qwen 只初始化受管服务，不先加载未使用的 Beauty。Qwen 配置、服务连接与模型加载分别显示：服务可连接不等于权重已预热，首次生成仍可能加载模型。明确使用 Beauty 时由原有人像准备任务按需加载并复用常驻服务。

1. 导入原片，补充角色和希望的效果。当前源码默认半合成、鲜明风格、沿用原场景；精修与大合成可明确选择，风格强度独立调整。
2. 查看检查计划、缺失能力、外发说明和预算，再开始。默认本地 Qwen 优先画质；视觉设计需要所选视觉服务，未用的 Beauty、抠图或原生分析模型不阻断该生成任务。
3. 默认开启独立审片、两轮条件改进及一轮零生图收尾：初审未达标才选择生成编辑或摄影融合并复审，保留最佳完整版本。同一次开始即可走完，无需先收下草稿再手动改进。默认上界为图像 3 次、视觉 10 次；首次编辑通过为图像 1 次、视觉 4 次。CPU 摄影融合不新增生图；已保存的一轮偏好继续保持。可关闭自动纠偏；关闭审片也关闭自动纠偏。
4. 查看原片与保存成片，缩放对照，按需导出 PNG 或真实保存母版。生成外观版本可查看、比较、审片、导出及明确发起新任务；旧 T/B/S、Beauty 和手工像素工具不适用于该版本。输出画布尺寸不代表生成了同等分辨率的相机细节。

可选形体调整仍属实验功能；跨图自然度、高清和同场一致性尚未完成产品验收。以上为当前源码的流程说明。独立程序包须经构建、安装和实际桌面全流程验收后才证明包含这些变更；离线测试不证明安装可用或艺术质量。当前实施与验收范围见 [产品目标](PRODUCT_GOAL.md)。

默认半合成保留拍摄地点，可合理调整部分场景和角色效果；不能静默室内变室外。生成同时负责人物与场景受光，避免抠回原人物覆盖模型已做的协调。普通导入参考仍可使用明确选择的“原景增强”与单区工具，其源域细节和零新增参考预算合同见 [原景增强与局部高清编辑](SOURCE_SCENE_ENHANCEMENT.md)，不等同于新默认生成路线。

额度绑定任务来源，候选选择、重开和重试不自动续发。请求结果未知须先核对已有请求；不通过再次点击改进自动重发。普通导入工具的未提交区域恢复仍须核验零提交证明。

明确使用原片/普通导入参考的人像美化工具时，BeautyGRPO 默认保留 100% 模型生成外观，接缝与真实遮挡单独融合。可降低强度或按人脸恢复原片；生成脸部纹理不称为相机细节。模型输出、软件执行和人工艺术批准分别记录。

制作时显示实际阶段、阶段用时和累计用时，新生成路线不显示虚构固定百分比；至少三次兼容成功实测才给出预计剩余时间。未触发的条件步骤不算已执行。保存或 AI 审阅通过后仍由用户检查当前版本并单独批准；艺术待修不等于软件崩溃。

升级程序后，打开保存版本会保留原效果，不隐式推理或补造合同。普通源域版本按其支持范围重新制作；生成外观版本明确发起新任务或按真实独立审片改进时，须重新展示计划与预算。失败、取消不覆盖父版本。启动默认打开最新保存结果；主动选择历史版本则保留该选择。

专业 Cos 画布表示当前任务依赖。新生成与纠偏图只读，条件步骤依真实执行更新；原生工具仍保留适用的参数与模板。当前不支持任意 DAG 或自由接线。

模型可放在 EXE 同级的 `model` 文件夹，或由模型管理选择已有安装目录；分析模型、BeautyGRPO 和图像服务分别显示状态，只要求当前计划实际使用的能力。标准目录和相对路径见 [model/README.md](../model/README.md)。逐项路径和 JSON 导入位于高级设置，配置保存在用户目录并用于后续启动。

程序包中的 `providers/beautygrpo.example.json` 是美化配置模板。独立运行时和权重仍须安装，详细字段见[人像美化配置](PORTRAIT_BEAUTY.md)。

原片/普通导入参考的“同时更新边界受光”可准备发梢和肩袖两层，预览后保存新版本；它不适用于完整生成外观。实际支持范围与未验收项见 [边界受光](BOUNDARY_LIGHT.md)。

指定工作区可在程序目录运行：

```powershell
.\cosplay-workbench.exe --root "D:\My Cosplay Project" --embedded-backend --auto-start-backend
```

双击 `Start-Cosplay-Studio.cmd` 可读取相邻 `.env`、`.env.local` 中的字面量配置。直接运行 EXE 时，在连接设置中配置，或预先设置进程环境变量。

程序包包含桌面依赖和许可，不包含模型权重、模型运行时、私人照片、工程或凭据。开发脚本、自动测试、构建工具及 Qwen 安装启动器位于同版本 `source.zip`；文档中“从源码运行”和构建命令需先解压源码包。
