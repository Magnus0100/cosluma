# 当前可编辑工程与导出

保存清单为 `outputs/runs/<run-id>/manifest.json`。版本拥有源基线、前景/覆盖率、背景、外观控制、效果层、准备快照和审核证据。父版本是祖先元数据，继续编辑不依赖历史诊断或父缓存。

## 工程交换

`.cosplayproj` 由 `portable_project.py` 打包导入，唯一格式为 `cosplay.portable-project.v2`。未保存编辑先保存，旧格式提取前拒绝，不自动迁移。

资产逐项记录 bytes 与 SHA-256，递归重写当前执行 JSON 路径。文件按字节验证，控制回执另核对规范化 JSON 语义身份。缺失、篡改、过时绑定、目录越界和同名覆盖均拒绝。

默认包含原片与参考。只有完整成对原生基线才允许省略原片，无参考工程必须包含原片。省略参考须保留重放资产；省略输入限制重新分析准备，不能称为完整素材交换。

权重、运行源码、运行时和凭据不入包；代码/模型路径只保留原生产者的诊断身份、字节数与SHA，不作为工程内必需编辑素材，也不随目标机器当前安装重标。新准备使用目标机器当前注册表，保存资产重放不推理。完整原片/参考包可在空目录建立工程配置，不自动改变现有版本选择。

## 真实母版

| 产物 | 当前含义 |
|---|---|
| `render_scene.tif` | 32 位浮点 `display_linear_sRGB`，文件名不表示场景 HDR |
| `render_master.tif` | 真实浮点渲染产生的 16 位显示母版，确定性 sRGB ICC |
| TIFF32 | 来自保存浮点母版，显式记录当前工作域 |
| TIFF16 | 来自真实 16 位母版，禁止 RGB8 乘 257 冒充 |
| PNG/JPEG | 当前保存成片的普通编码输出 |

限幅在实际显示编码边界消费。RAW 源处理的场景线性域不作为最终默认。缺真实母版/工作域时失败，不用源图 TIFF、预览或旧文件补齐。

验证工程交换时，分别检查母版字节、JSON资产绑定、导入后的原生ROI和保存/实时画面；重开不应取得新的网络或推理预算。文件一致性不授予成片批准，质量状态与人工审片须绑定所导出的已保存版本。安装与模型配置见 [INSTALLATION.md](INSTALLATION.md)，开发验证见 [DEVELOPMENT.md](DEVELOPMENT.md)。
