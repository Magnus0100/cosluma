# 当前可编辑工程与导出

保存清单位于 `outputs/runs/<run-id>/manifest.json`。当前范围制作以冻结的 `photo_appearance` 为像素依据：`source_baseline` 保存原片原生 float 基线，`mixed_regional` 保存部分生成覆盖与其余父项像素，`generated_full` 保存不透明整图生成外观。局部编辑仍严格限定核心范围；获准的半合成／大合成联合整图编辑若返回透明或半透明像素，以全画幅核心记录真实混合覆盖，不冒称全画幅生成所有权。精修范围不允许借半透明输出绕过整图重画限制。保存图、母版和资产内容身份分别核对；文件存在不代表画质通过或人工批准。

生成响应保留实际 PNG alpha 和原始响应身份；透明色的隐藏 RGB 不参与合成。颜色在线性光中预乘 alpha 后与 alpha 分别注册，局部覆盖再乘既有核心羽化，透明及许可范围外的父项 float 保持逐值一致。生成覆盖按实际不透明度继承，不能把该 alpha 当人物抠图，也不因此默认启用生成遮罩。保存、拥有证据副本、重开与导出均使用同一冻结母版和覆盖率。

普通原片／导入参考的有效原生图层仍可交换。已退役的创建和外观格式不支持，不自动迁移或恢复旧流程。

## 工程交换

`.cosplayproj` 使用 `cosplay.portable-project.v3`。旧包及退役的生成外观格式拒绝，不自动升级。

包内每项记录字节数与 SHA-256。typed 外观资产按不可分的组传输：保留原始 `receipt.json`、float32 NPY、PNG 及覆盖率／生成证据文件的字节，组内相对布局固定；内外 ZIP 使用存储方式，避免大浮点平面反复压缩。`cosplay-appearance://<asset-id>` 只作为包内定位符，导入后变为该版本拥有的目录。回执内容、`asset_id`、预览及母版身份不因迁移重写。

普通执行 JSON 的素材路径会重定位，嵌套依赖的字节和校验关系重新核验。当前 session 的绑定、模型观察、响应和独立审片保持原内容；自持证据索引用 SHA 定位对应文件和 typed 资产，索引内的相对布局及审计路径不重写。导入只调整 session 顶层的证据读取位置，不重签 `session_id` 或 `context_sha256`。同版本完整素材包可从新的公开任务检查入口按明确反馈继续制作；仍须核验当前 producer、运行配置和新任务预算，不恢复在途请求或继承人工批准。

模型、代码和历史来源身份只作诊断数据，不改签为本机执行证据。未声明成员、重复成员、组内文件缺失或篡改、目录越界、运行文件及同名覆盖均拒绝。只重算外层包哈希，不能把被破坏的组成员或回执变为有效资产。提取失败清理本次新目录，打包失败清理未完成包和临时资产组。

默认包含原片和参考。typed 工程即使省略原始 RAW 或独立参考文件，也必须保留原生基线和选中的完整外观组；它们可在原目录或父版本不可用后重开、查看已保存画面并导出。证据副本不暗中包含被省略的 RAW；实际评价必需的显示预览仍保留。省略素材不构成完整素材交换，不能据此重新分析原始 RAW、恢复在途模型任务或继续消费旧额度。普通原生工程省略原片仍须满足其已有的成对基线合同。

权重、运行源码、运行时和凭据文件不入包。新制作需重新检查目标机器当前配置与权限；保存资产回放不推理、不下载模型，也不因此获得新的人工批准。完整素材包可在空目录建立工程配置，导入不自动替换已有版本选择。

## 真实母版

| 产物 | 当前含义 |
|---|---|
| typed `master.npy` | 该冻结资产的权威 float32 `display_linear_sRGB` 像素 |
| typed `preview.png` | 与权威 float 母版匹配的实际显示预览，迁移保持原字节 |
| `render_scene.tif` | 已保存 32 位浮点 `display_linear_sRGB` 母版，文件名不表示场景 HDR |
| `render_master.tif` | 由实际 float 像素编码的 16 位显示母版，带确定性 sRGB ICC |
| TIFF32 / TIFF16 导出 | 复制对应已保存母版并核验字节 |
| PNG 导出 | 复制当前已保存 PNG 并核验字节 |

不通过预览 PNG 或原始 RAW 重建已经拥有的 float 母版，不用 RGB8 乘 257 冒充 16 位精度。缺失母版、工作域或绑定时失败；原生来源与生成来源分别描述，不把生成细节称为相机纹理。

验证工程交换须分别检查 NPY／PNG／回执原字节、导入资产绑定、原目录消失后的只读重开与导出，以及损坏／路径攻击拒绝。技术往返不授予审美通过，也不证明过程恢复或模型出品质量。安装与模型配置见 [INSTALLATION.md](INSTALLATION.md)，开发验证见 [DEVELOPMENT.md](DEVELOPMENT.md)。
