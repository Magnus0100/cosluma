# 局部几何配准计划

## 结论

当前的中心缩放加平移已经解决了可解释的整体误差，但不能解决 GPT 重新绘制造成的局部形变。对现有两组真实原片实测：

| 样本 | 全局结果 | 结构分歧均值 | 分歧分数 ≥ 0.25 |
| --- | --- | ---: | ---: |
| DSC02631 | scale 1.00，dx 0，dy 0，edge score 0.762 | 0.0633 | 5.9% |
| DSC02634 | scale 1.01，dx -2，dy +16，edge score 0.618 | 0.1050 | 11.3% |

分歧集中在脸、刘海和飞发、手指及逆光服装轮廓。它们属于生成模型重绘，强行用原片纹理覆盖会产生双眼、双手和发丝重影。稳定的胸口、衣服大片、腰部和饰品可以继续使用原片高清细节。

## 十小时内的实现顺序

1. **先做局部配准诊断（约 1 小时）**：在 4×5 或 6×8 proxy 网格中，对每个网格做 ±8 proxy 像素的边缘相关搜索，输出 `local_shift.json` 和箭头叠加图。只采纳相关分数高、邻域位移连续的格子；孤立的大位移标记为结构分歧。
2. **加入可选 mesh displacement（约 3 小时）**：以 source 画布为目标，用网格位移双线性插值采样 reference。位移先限制在画幅的 1–2%，边界使用复制采样。默认不启用，先生成 A/B 图。
3. **增加保护区（约 2 小时）**：mask 中将脸、头发、抬手和手指设为 `geometry_protected`，这些区域不应用 mesh warp，也不提高 alpha；躯干/服装区域才允许小位移。保护区可以先用归一化矩形/多边形 JSON 配置，后续再换模型分割。
4. **做两组样本 A/B 验收（约 2 小时）**：比较当前 global alignment、local warp、local warp + structure-safe 三者。验收条件是衣服拉链/肩章/腰线重影减少，脸和手部不出现变形，背景直线不被拖弯。
5. **封装和文档（约 2 小时）**：把位移和保护区写入每个 sample 的 metadata；加入 `--local-warp`、`--local-warp-map` 开关。默认关闭，只有 A/B 证明收益后才对稳定服装区域开启。

## 推荐接口

```json
{
  "DSC02634": {
    "enabled": false,
    "grid": [6, 8],
    "max_shift_proxy": 8,
    "max_shift_fraction": 0.015,
    "anchors": [
      {"x": 0.50, "y": 0.52, "dx": 0.0, "dy": 0.0, "confidence": 1.0}
    ],
    "protected_polygons": [
      [[0.36,0.18],[0.65,0.18],[0.67,0.43],[0.34,0.43]],
      [[0.58,0.30],[0.76,0.30],[0.80,0.60],[0.56,0.60]]
    ]
  }
}
```

`dx/dy` 采用 source 画布的归一化坐标，采样方向为 output(source) → aligned reference。保护区优先级高于网格位移：保护区内位移系数置零，同时把 alpha 保持在较低的结构安全上限。

## 不采用的方案

- 不在当前阶段下载或训练姿态模型；两组样本的主瓶颈是生成结构不可控，而不是缺少人物轮廓。
- 不对整个人物做 TPS/全脸 landmark warp。少量错误 landmark 会把眼睛、手指和发丝拉成长条，且难以发现。
- 不把局部相关得到的孤立位移直接写回最终图；必须经过连续性、位移上限和结构分歧三重门控。

## 验收标准

- 稳定服装边线与原片纹理的双边缘明显减少。
- 脸、头发、手部的生成结构保持完整，不出现可见拉伸或重影。
- 背景桥架和地砖直线在局部 warp 前后误差不增加。
- 默认命令行为保持不变；所有局部 warp 参数都写入 `metadata.json`，可以一键复现。
