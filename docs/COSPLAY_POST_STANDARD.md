# Cos 成片标准

当前目标是以人物为主的完整角色摄影：保留本人妆造，完成精修、场景、合适的氛围、空间融合与光色。brief `cosplay-post-v6`、风格 `cosplay-character-portrait-v3`。用户限制优先，未知角色从可见造型设计，事实与创意分记。

## 六项视觉验收

| 项目 | 成片应达到的表现 |
|---|---|
| 本人和妆造 | 对照原片，五官比例、非对称特征、表情、眼线、唇线和美瞳图案仍可辨认；手指、配饰与服装结构正确；颜色可以适应场景 |
| 角色与场景 | 第一眼看到人物、妆造与角色重点；默认延续原地点、室内外属性与布局，局部整理与替换服务人物；背景不能以更高的反差、亮度和复杂度抢走注意力 |
| 特效空间 | 主效有前中后景、遮挡、尺度、虚实和清晰的作用范围；发光效果影响附近材质；脸、手和造型重点可读；特效数量不作为完成度标准 |
| 光色融合 | 脸、双臂、衣料与背景属于同一场景；肤色过渡连续；眼白、虹膜、唇妆与衣料响应各有区别；没有孤立怪色、贴纸边缘或等宽发光描边 |
| 高清后期 | 100% 查看皮肤、发丝、衣料和金属细节；亮部有纹理，暗部有层次；没有糊边、锯齿、重复纹理、残留原背景或明显穿帮 |
| 符合风格的完成度 | 清透、精致、暗调叙事或幻想方向，均须有明确人物表现、光影塑形与材质色彩；暗调仍有皮肤高光、眼神和丰富暗部；特效按需要使用，场景改造与特效数量不证明风格完成度 |

全图先看构图、主题和光色，再以原尺寸检查眼口、手部、服装、发丝与边缘。分别对照原片、设计参考和最终合成，记录改善与退步。参考生成成功、保存成功与视觉接受分别登记。

## 统一生产职责

| 阶段 | 职责 |
|---|---|
| 检查计划 | 输入、制作范围、模型能力与预算；此时不推理 |
| 观察与基线 | 实际原图观察、原片 float 基线及独立基线评价 |
| 模型选工具 | 按许可选择摄影调整、局部生成或联合整图编辑，记录实际覆盖与像素来源 |
| 独立审片 | 先整图，再看实际编辑区域；自然可信度与创作收益分别判断，塑形另审目标完成度 |
| 有界改进与保存 | 在原预算内保留较好完整版本，失败和取消保留父版本 |
| 重开与导出 | 使用真实保存母版，分别核对像素、精度和人工接受 |

保存原片身份和观察事实不等于覆盖全部生成 RGB。新增受光及内容按当前资产职责保留；图像变化或审片通过均不自动授予人工批准。

## 区域编辑的边界归属

显式 scoped 编辑的授权核心区里，谁写入由**本轮授权操作**决定，不由核心区里有没有主体决定：

| 本轮授权 | 核心区内的写入 |
|---|---|
| 含 `scene_edit` / `scene_cleanup` / `scene_composite` | 场景侧是本轮授权内容，必须写入，并被接合与联合光照覆盖 |
| 含 `relight` | 跨边界联合光照，两侧都必须被写入并被同一求解覆盖；只写主体一侧在语义上不成立 |
| 无上述操作但 `scene_policy ≠ preserve` | 同上：本轮允许改变场景，场景侧按授权写入 |
| 仅人物类操作（`portrait_retouch`、`detail_repair`）且 `scene_policy == preserve` | 才由当前画布的真实主体分割收窄：主体像素归生成层，场景像素保留父级字节 |

判定原则一句话：**授权内容永不静默丢弃；拿不准时选"写"**。

主体分割（`source_alpha` 的 BiRefNet 剪影）是分割，不是许可：权重 ≤ `soft_low=0.02` 的像素算场景侧，≥ 0.5 算主体；整画布、纯色、矩形、标签图和编辑覆盖率都不能充当它。核心区内主体像素少于 `minimum_subject_pixels=256` 时不收窄，保留预留写入并记录 `authorized_core_without_subject`；分割缺失、运行时不可用或被显式关闭时退回已评审的矩形接合，并记录缺失原因，不静默改判。

收据的 `boundary_source` 以接合（`join.subject`）实际写下的边界为单一事实来源：收窄轮次为 `subject_matte_edge`，授权全写轮次为 `authorized_rectangle`，接合前的声明只留在 `acquisition`。场景侧的交付改动量不得为 0。

## 原片与普通导入参考的专项审片与修复

`cosplay_post_review.v2` 按 `cosplay_review_scope.v1` 分开记录整图艺术、场景上下文、匹配原生窗口、眼口特征和覆盖缺口。`cosplay_native_review_inputs.v2` 保存实际可用的眼口/双手/双臂/发丝/衣料/边缘/接地/高光证据；检测不足或无已知源支持的区域保持unknown。各项 pass/fail/unknown/unavailable，抽样与缺失可见。局部通过仅覆盖所见匹配窗口，整图艺术通过不认证全图原生细节；局部fail仍保留，自动审片不授予人工批准。

参考生成纠错消费完整当前QA中明确归因于参考的失败，使用原片、参考和受限mask多参考编辑。参考是目标画布，原片给身份/原始观察，mask限范围。核对请求/输出/画布及失败项，先做原生staging子版本，再复审实际成片。请求成功不是融合资格，失败/unknown/unavailable保留草稿，预算不递归，不自动批准或切换。

已保存成片的 `repair-final` 先取得完整当前像素绑定的新QA，按实际职责审查材质、背景、人物环境响应及人物/接收面原尺寸细节恢复资格，执行一次有资格的本地处理并复审新子版本。参考与独立效果生图预算为零；未知先补证据，源精修或空间能力未获资格时保留具体问题。同像素继承QA仅显示历史出处，不能授权当前修复。

`native_receiver_detail`只处理鞋部匹配窗口中明确的 `native_detail fail/native_retouch/retouch_missing`，且该窗口的身份和材质观察须通过。实际审片、源/成片像素、共同地面支持、原始及当前覆盖率和采样有效性共同限定可恢复区域。对分割漏掉的鞋下短缺口，必须有当前源鞋语义、向下鞋底轮廓、连续共同地面终点及无不透明前景的路径，长度随鞋宽和参考采样间距自动限制。只恢复背景亮度细节，人物预乘像素、透明度与接触衰减保留；混合边缘有羽化，设计背景的低频色彩基础沿用并报告亮度漂移，不重画人物或制造反射。高覆盖率或无共同地面支持的区域继续未知；保存子版本后须重新看整图和匹配原尺寸窗口，恢复回执与数值改善不能替代实际视觉通过。

原生精修增量在显像和前景分解前一次，保存重开不再识别。无批准修补的零改动是保源事实，不能宣传完成精修。

## 边界

背景后方/旁侧效果随合格背景保留，独立 RGBA 支持 behind/front、over/emission_add，须实际效果与合成质量门，不自动产生材质受光/投影/镜面反射。接触仅在鞋底、对应、接收面共同支持范围。

合同、数值重放、搬迁、导出及启动证明工程闭环，六项成片须真实视觉证据。接受作品须解决必需失败和必要的身份/眼口/主效未知项、明确原生检查范围，并取得当前已保存版本人工批准。作品结果保存在用户工程中，生产职责见 [PRODUCT_ARCHITECTURE.md](PRODUCT_ARCHITECTURE.md)。
