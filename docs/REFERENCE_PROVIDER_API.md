# 当前参考图服务

Provider 位于 `providers/registry.json`，公开连接由 `provider_settings.py` 管理。密钥来自本机凭据，不写工程、来源文件或日志。

`reference_provider.py` 执行图像请求。当前创建由 `photo_art_direction.py` 观察原片，`photo_editing.py` 编译模型专属设计，`photo_edit_session.py` 与工具执行首次编辑和有界改进。当前资产由工程选择和哈希决定，没有某张样图作为全局默认。

所有 provider 使用同一 checked 生产入口。0.7 开发流程先冻结原片浮点基线，由模型选择首次摄影处理、局部编辑或联合整图编辑；Beauty、T/B/S 与边界补光不是创建必经阶段。默认一个候选、最多两轮通常改进，另有一次仅允许零生图工具或停止的收尾；视觉设计和独立审片默认开启，上限为三次图像和十次视觉请求。收尾不授权生图，显式只设置一次改进不增加收尾。多候选共享基线审片及后续额度；重开、切换、未知与停止请求不重置预算。关闭审片仍实际编辑并保存未审草稿。

Qwen 默认使用当前注册的官方 BF16 画质配置，图像服务与视觉决策服务分别配置，见 [QWEN_IMAGE_LOCAL.md](QWEN_IMAGE_LOCAL.md)。GPT 与 Qwen 使用相同创作目标、不同模型文本编译，实际发送指令保存在工具请求记录中。

生成记录 Provider、模型、发送文本、实际输入、工作流、请求和输出。`photo_appearance` 保存浮点母版、预览与生成覆盖；局部许可外保留上一版浮点像素。图像请求成功不等于作品通过，已知图片在审片超时后保留为待核查草稿。

远程 OpenAI 兼容单图请求的输入长边上限为 2048：超过上限的栅格生成独立 API PNG 副本，按 EXIF 定向、转换至 sRGB，透明颜色在线性预乘空间与 alpha 同步缩小；小图保留原始请求字节，不放大或无故重编码。该副本的直接父输入（可能是当前最佳裁图）与路径、SHA、原尺寸分别记录，API 副本另记实际路径、SHA、尺寸、格式和字节数，不改变原图、裁图、浮点母版或生成响应。RAW 继续使用其既有显示 JPEG 边界。本机 Qwen 栅格及有序条件图仍保持原字节和精确画布，二值遮罩与身份裁图不单独缩放。2048 是本软件的输入准备策略，不表示已查明远程服务的字节拒绝阈值；HTTP 失败不自动重试或刷新额度。

受检查的本机 Qwen 多图工具可提供有序 `[source, edit_mask]` 条件：source 是实际母版裁图，mask 为同尺寸、同坐标的 L 模式二值图，双方路径和 SHA 均核验。mask 是模型软条件，实际像素保护仍由工具的许可范围及线性预乘合成执行。原材质校正的 `[scene_reference, source_identity, edit_mask]` 三图合同独立核验；远程单图 adapter 不接受显式多图条件。当前脸部塑形使用确定性几何工具，零次图像生成，不走这条 Qwen 生图路线，见[形体调整](REVERSIBLE_SHAPING.md)。

周期网格诊断对不透明栅格保持原有亮度计算；透明输出先在线性 sRGB 中预乘 alpha，再分别观察黑、白中性背景上的可见颜色。全透明像素的任意 RGB 不能改变判定，两组背景的相关峰也不能混合成证据。每组仍要求原阈值上的双谐波和邻峰差；这项诊断不授予轮廓自然度、创作收益或人工接受。最终区域合成仍须观察实际母版、覆盖与 alpha 共同产生的像素。

完整模型返回后的品质拒绝仍保留实际提交成本。只有实际 owner、原始输入、上传与提交工作流、完整成功终态、拒绝收据及返回像素的 SHA 全部匹配，才可把该次请求核清为已知结果；错误文字、伪造状态或部分证据不能授予重试。核清不退款、不自动重发、不注册或发布拒绝图，也不改写旧的 producer 或审片结论。

普通导入参考默认零新增生图，仍使用其源域图层工具；显式原景单区任务和参考修复各自遵守当前检查合同，见[原景增强](SOURCE_SCENE_ENHANCEMENT.md)。这些能力不构成 scoped 创建的隐式兼容流程。

具备原生源域编辑合同的已保存版本，可通过 `POST /api/source-runs/<id>/repair-final` 做本地修复：取得新的当前绑定QA，审查材质或背景资格，有资格时保存独立修复版本并复审。该任务的参考与独立效果生图预算为零；未支持或资格不足的问题保留。请求与纠错合同见 [GENERATION_PROMPT.md](GENERATION_PROMPT.md)，当前入口见 [REVISION_API.md](REVISION_API.md)。
