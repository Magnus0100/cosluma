# 产品目标与取舍

普通用户导入原图、说明角色和希望的氛围，通过同一 AI harness 和生产路径得到人物可信、设计明确、光照融合的高清 Cos 作品。实现范围、实际效果、安装与人工接受分别验收。

## 制作范围

| 类型 | 修改范围与验收重点 |
|---|---|
| 精修 | 保留人物和原场地，改善人像、光影、杂物与明确局部缺陷；自然且有可见收益 |
| 半合成 | 在原场地内补充局部场景、角色效果及联合受光；身份、姿态、重要道具和场地逻辑可信 |
| 大合成 | 根据明确授权建立新场景；透视、尺度、遮挡、接触和人物环境受光协调 |

自然、鲜明、戏剧是独立风格轴。默认半合成、鲜明、沿用原场景；改变室内外属性、姿态、重要道具或形体须分别获得明确授权。生成外观承担实际覆盖的像素，不能再用整个人物原片 RGB 覆盖已成立的新受光。

合成作品的形体调整安排在合成、调色、调光和人物环境融合完成后：先保存这一阶段的成片，再以它作为独立塑形母版 U。塑形直接消费成片的外观与受光，改力度从同一 U 重算，关闭恢复 U；上游外观更新后须建立新的 U。塑形后重点复核脸颈阴影、发丝、衣物、接触关系及背景线条。

## 验收边界

- 身份、妆造、姿态、服装和道具可信，皮肤、头发、脸颈与遮挡边界自然。
- 创作收益符合本次制作类型和用户要求，超过无目标的统一调色或堆砌特效。
- 先看整图的主题、设计和光照，再检查实际编辑区及必要原尺寸细节。
- 保存、重开、复制与导出保留真实母版及图层职责；生成纹理和扩大画布不等于新增相机细节。
- 可选形体调整默认关闭，改力度从同一母版重算，关闭精确恢复；失败和取消保留当前版本。具体合同见[可撤销形体调整](REVERSIBLE_SHAPING.md)。
- 必要区域高清与同场风格一致性分别验证，不能用单张或同一人物通过代替泛化。
- 当前安装须能独立启动和完成保存导出；源码检查、构建启动、模型执行、像素质量和人工接受分别记录。

## 开发与交付

每轮只关闭一个明确的用户操作，先复用现有输入和结果做最小复现及收益验证，再完成针对性检查和交付检查。性能、画质、功能和安装分项报告；未通过或未执行保留原结论，不以测试数量代替交付。

禁止按文件名、固定人物坐标、特定颜色或单张参考相似度修改生产行为。确需模型验证时，先选一张相关代表图，必要时增加极少量差异样本；稳定后的最终套图另作串行交付。

只支持当前生产合同。删除被替代的代码、格式与说明；当前保存、重开、复制和导出必须完整，不为架构清理删除用户作品。失败、取消和未知请求保留预算事实，不换 run 重置额度或重签旧回执。

架构见[产品数据流](PRODUCT_ARCHITECTURE.md)，工作方法见[AI harness](AI_HARNESS.md)，当前待办见[工程状态](ENGINEERING_STATE.json)。实际执行和像素证据保存在私有工程中，不混入公共使用指南。
