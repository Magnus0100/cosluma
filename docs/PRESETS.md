# 当前配置与预设

当前brief `cosplay-post-v4`，风格 `cosplay-complete-v2`。`preset_store.py/provider_settings.py` 保存 `presets/presets.json`、`providers/registry.json` 和公开连接设置。模型由当前本地注册表管理。

预设决定方向，本图计划决定布局，预设不是渲染结果或质量承诺。

| 风格 | 方向 |
|---|---|
| 清透角色写真 | 干净背景、柔和光色、清晰材质 |
| 舞台角色海报 | 舞台、聚光、光束/雾及遮挡 |
| 电影夜景 | 夜景深度、光源、人物环境共同光色 |
| 柔和人像精修 | 皮肤妆造、深度、自然衔接，可无特效 |
| 电影逆光 | 方向性发丝/材质高光、环境补光 |
| 幻想氛围 | 可见造型的发光主题、空间和响应 |
| 暗调仪式氛围 | 仪式、红金层次、烟雾/光线 |

五官、妆造、美瞳、姿态、服装和相机保持，颜色可适应场景。用户禁特效/保背景优先，研究事实与创意分记。切换风格保留 brief，只改受管理段及旧自动设计；精确重试保留文本、版本和快照。“恢复默认”才重置文字。

整体/颜色/明暗消费 `reference_appearance_stack.v2`，与生图风格分别记录。背景效果随合格背景消费，跨人物效果走独立 RGBA 并审核。轮廓响应、投影及发光要求需真实资产和作品证明。

见 [GENERATION_PROMPT.md](GENERATION_PROMPT.md) 与 [COSPLAY_POST_STANDARD.md](COSPLAY_POST_STANDARD.md)。
