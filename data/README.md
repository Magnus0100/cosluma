# Local data

Original photos, references and user artwork are private inputs and are excluded
from public source and binary releases. Store camera originals in `raw/`,
references in `reference/`, and imported artwork in `manual/`, or select files
outside the checkout. Edited results are saved as independent project versions;
source images are not overwritten.

Create a workspace with `python scripts/project_cli.py init <directory>`.
The desktop release creates a writable workspace in the user's local application
data directory. See [installation](../docs/INSTALLATION.md).
